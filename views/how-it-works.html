Design choices

  • Speaker = source. Mic is ME, tab is THEM. No diarization model needed, and labels are never wrong (unless your speakers bleed into the mic, so wear headphones).
  • No keys, nothing sent for AI. Speech to text and the coach run on this computer. Audio and transcript never go to an AI service. The server only stores sessions and shared recaps.
  • Two coach models. Auto uses Chrome's built-in Gemini Nano when it's already on disk, and Qwen 3.5 2B (4-bit, WebGPU) otherwise. Both return a fixed JSON schema.
  • Downloads once. Moonshine (about 155 MB) and Qwen (about 1.3 GB) are cached by the browser after the first load. “Check this computer” loads and times them before a call.
  • Context is per call. The context box (who, goals, facts not to overstate) goes into every coach, strategy and recap call. Presets fill it; each saved session keeps the context it ran with. It never goes into a shared recap.
  • Recap on Stop. One pass of the local model over the numbered transcript (long calls keep the most recent part that fits): summary, what went well, misses linked to their line, next step, follow-up email draft, CRM notes.
  • Sharing. “Share recap” makes a link with a random id and an 8-character code, shown once. Send them separately. 5 wrong codes lock the recap for 15 minutes; it expires after 14 days; Revoke deletes it at once.
  • A voice detector cuts turns at pauses (0.7s), tracking each lane's background noise. Monologues are cut every 14s so text keeps coming.
  • One coach call in flight. New lines during a call mark it dirty; it re-runs once when done. Never queues a backlog.
  • Structured output. The model is constrained to a fixed JSON schema, so the UI can't break on a chatty reply.
  • Fails soft. A failed coach call keeps the last advice on screen and retries. Mic, tab-share and model problems show a plain-English fix in the sidebar.

What I'd build next

  • Stream the coach response so the “Now” line lands sooner.
  • Recap long calls in pieces so nothing is cut.
  • CRM write-back for the recap's notes and next step.
  • Meeting bot mode (join Zoom/Meet as a participant) for the other side's audio without tab sharing.
  • Team mode: playbooks per deal stage, scorecards across reps.
